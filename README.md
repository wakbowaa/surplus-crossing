# Surplus Crossing

One table has extra seedlings. Another needs them. Their words do not quite match.

Neighbors post bounded offers and needs from distinct description sources. Once the host closes the gate, validators normalize every listing into a family and identify materially incompatible offer-need pairs. Contract code, not the model, moves units across the crossing: same family, no blocked pair, never more than either side declared.

No listing is custody, payment, or a delivery promise. The stored match is a capacity-preserving coordination plan that keeps the original owners and sources visible.
